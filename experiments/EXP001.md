# EXP001 — Registry Record

- **Experiment ID:** EXP001
- **Title:** Script-Based Language Detection
- **Status:** completed
- **Objective:** Eliminate false Arabic classifications for English messages containing digits.
- **Hypothesis:** Language routing should use script evidence rather than digit presence.
- **Baseline:** Arabic if Arabic script OR any digit is present.
- **Intervention:** Arabic only when Arabic Unicode script is present; otherwise English.
- **Metrics:** language detection accuracy on controlled language cases; B005 regression case.
- **Result:** The changed function classified English + number as English while preserving Arabic-script classification in the documented isolated checks.
- **Decision:** keep
- **Motivation:** B005 baseline failure.
- **Implementation:** `detect_language()` change in `agents/conversation_agent.py`.
- **Validation limitation:** Full repository execution remains blocked in this environment by outbound GitHub DNS/network restrictions.

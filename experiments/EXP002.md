# EXP002 — Embedding-Based Intake Relevance

- **Experiment ID:** EXP002
- **Title:** Embedding-Based Intake Relevance
- **Status:** completed
- **Objective:** Replace unreliable binary LLM relevance classification during structured intake.
- **Hypothesis:** The local embedding model provides a more consistent relevance signal than the local 3B LLM for short intake answers.
- **Baseline:** `llama3.2:3b` binary YES/NO classification after semantic similarity measurement.
- **Intervention:** Use `nomic-embed-text` cosine similarity as the deterministic intake relevance gate.
- **Metric:** Cosine similarity between the current interview question and user answer.

## Controlled measurement

| Question type | Relevant | Irrelevant |
|---|---:|---:|
| Age | 0.689 | 0.372 |
| Occupation | 0.618 | 0.414 |
| Living situation | 0.662 | 0.445 |
| Reason for seeking help | 0.501 | 0.382 |
| Substance use | 0.477 | 0.356 |

Relevant examples ranged from **0.477 to 0.689**. Irrelevant examples ranged from **0.356 to 0.445**.

## LLM classifier check

The local `llama3.2:3b` classifier returned `NO` for the clearly relevant answer:

> I am 30 years old, I work as a software developer, and I live in Cairo.

The same result occurred after adding few-shot YES/NO examples. This makes the model unsuitable as the primary binary relevance gate for this intake task.

## Decision

Use an initial embedding threshold of **0.46**. This threshold accepts all five measured relevant examples and rejects all five measured irrelevant examples in this controlled sample.

## Limitation

This is an initial empirical prototype threshold, not a production-calibrated classifier boundary. A larger labeled validation set is required before treating 0.46 as a stable operating threshold.

## Implementation

`agents/conversation_agent.py` now uses `ANSWER_RELEVANCE_THRESHOLD = 0.46` and records the threshold and validation method in observability metrics. The LLM remains available for conversational generation but is no longer used for this binary intake decision.

# Roadmap

## V1 — System foundation
Stabilize conversation flow, state contracts, memory boundaries, and API behavior.

## V2 — Evaluation
Add reproducible conversation tests, retrieval/memory metrics, and model/prompt experiments.

## V3 — Failure Observatory
Classify dialogue, retrieval, state, voice, and infrastructure failures.

## V4 — Productionization
Observability, validation, authentication/rate limiting, CI/CD, deployment.

## V5 — Advanced conversation
Personalization, tool use, stronger memory strategies, and provider abstraction.

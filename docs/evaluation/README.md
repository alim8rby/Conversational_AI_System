# Evaluation

Evaluation is a first-class product component.

## Initial metrics
- Task completion
- State-transition accuracy
- Retrieval precision/recall
- Memory relevance
- Response quality
- Grounding / unsupported claims
- Latency and cost
- Voice generation success

## Method
Use a reproducible conversation benchmark with expected state transitions, relevant memories, and quality criteria. Run regression evaluation whenever prompts, models, or memory logic changes.
